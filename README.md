# VitaDent

Статический сайт стоматологической клиники VitaDent.

## Запуск

Откройте `index.html` в браузере или разместите всё содержимое репозитория в корневой папке статического хостинга. Для локального сервера:

```bash
python3 -m http.server 8000
```

Сайт не требует сборки. Шрифты, изображения, стили и скрипты находятся в папке `assets`.
